# 🏦 Bank System

مشروع نظام إدارة بنك مطور بلغة **C++** كجزء من التطبيق العملي لمفاهيم البرمجة كائنية التوجه (OOP).

## 🚀 المميزات الأساسية
* **إدارة العملاء:** إضافة، تعديل، حذف، وعرض العملاء.
* **العمليات المالية:** سحب، إيداع، حساب إجمالي الأرصدة، وتحويل الأموال.
* **إدارة المستخدمين:** تسجيل دخول وصلاحيات كاملة للمستخدمين.
* **إدارة العملات:** عرض العملات وحاسبة تحويل العملات.
* **التخزين:** حفظ البيانات باستخدام ملفات نصية (`.txt`).

## 🛠️ التقنيات المستخدمة
* **اللغة:** C++
* **البيئة:** Visual Studio
* **النمط:** Object-Oriented Programming (OOP)
